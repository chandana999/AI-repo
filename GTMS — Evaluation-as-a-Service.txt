Evaluation Types
RAG Evaluation Metrics
1. Faithfulness

Measures whether the answer is grounded in the provided context
Detects hallucinations and unsupported claims
Critical for factual accuracy
2. Context Recall

Measures how much of the ground truth information is present in the retrieved context
Evaluates retrieval effectiveness
Higher recall = better context retrieval
3. Context Precision

Measures how much of the retrieved context is relevant to the question
Evaluates precision of retrieval
Higher precision = less noise in context
4. Answer Relevancy

Measures how relevant the answer is to the question
Evaluates answer quality and usefulness
Higher relevancy = better user experience
5. Factual Correctness

Measures factual accuracy of the answer
Compares answer against ground truth
Critical for production systems
6. Context Entity Recall

Measures recall of entities from the ground truth in the retrieved context
Evaluates entity-level retrieval performance
Important for entity-heavy queries
7. Noise Sensitivity

Measures system robustness to irrelevant context
Evaluates how well system filters noise
Important for production reliability
Agent Evaluation Metrics
1. Tool Call Accuracy

Evaluates LLM's ability to identify and call required tools
Measures correct tool selection and parameter usage
Critical for agent functionality
2. Agent Goal Accuracy

Binary metric: did the agent achieve the user's goal?
Measures task completion success
Core agent performance indicator
3. Topic Adherence

Ensures agent stays "on-topic" and doesn't stray from intended use case
Similar to faithfulness for agents
Maintains use case boundaries
