What is Advanced Retrieval?
Advanced Retrieval refers to sophisticated techniques beyond basic vector similarity search that improve the accuracy, relevance, and performance of RAG (Retrieval-Augmented Generation) systems. These methods combine multiple strategies to retrieve the most relevant context for LLM applications.

Key Benefits:

Improve retrieval accuracy and relevance
Handle diverse query types and use cases
Optimize for both precision and recall
Reduce hallucinations through better context selection
Enhance RAG system performance

Advanced Retrieval Types
1. Naive Retrieval

Basic vector similarity search using embeddings
Simple cosine similarity between query and document vectors
Foundation for other advanced techniques
Use case: Baseline retrieval, simple semantic search
2. Best-Matching 25 (BM25)

Sparse lexical retrieval based on bag-of-words
Compares text similarity based on word overlap
Better for exact keyword matches and lexical queries
Use case: Keyword-heavy queries, domain-specific terminology
3. Multi-Query Retrieval

Generates multiple query reformulations using LLM
Retrieves documents for each reformulated query
Combines unique documents from all queries
Use case: Improving recall, handling ambiguous queries
4. Parent-Document Retrieval

"Small-to-big" strategy: search small chunks, return parent documents
Stores parent documents separately from child chunks
Balances precision (small chunks) with context (parent docs)
Use case: When context surrounding matches is important
5. Contextual Compression (Reranking)

Two-stage retrieval: retrieve many, rerank to top results
Uses reranker model (e.g., Cohere) to score query-document pairs
Compresses retrieved context to most relevant documents
Use case: Improving precision, reducing noise in context
6. Ensemble Retrieval

Combines multiple retrieval methods (e.g., BM25 + embeddings)
Merges results from different retrievers
Leverages strengths of each method
Use case: Maximum recall and accuracy
7. Semantic Chunking

Chunks documents based on semantic meaning boundaries
Preserves context and meaning within chunks
Better than fixed-size chunking for semantic search
Use case: Maintaining document coherence in retrieval
